## 项目自身的代码约定（其他 Agent 必读）

- **Python 入口**：本机 `python` 可能命中 Microsoft Store 别名。跑测试使用项目环境中的 Python 3.10+ 解释器；本机若使用 Codex 运行时，替换为该环境的实际路径即可。
- **源码根**：`src/`，包名 `screen_mouse_recorder`，需把 `src` 加入 `PYTHONPATH` 或用 `pip install -e .`。
- **模块搬家规则**：见 MODULE_BOUNDARIES.md。移动函数优先 re-export 保旧路径。
- **数据/AI 边界**：AI 与外部工具只产候选（`needs_review` / `excluded`），不得直接写 `confirmed`；只有人工复核文件能生成正式确认数据；图表只读确认数据源；每个结论要能追溯到帧/视频时间/证据。
- **出图**：三类图由确定性 Pillow 脚本生成，**无图片 Prompt**；大模型只产结构化 JSON（分类/开放条件/重要度），绘图由脚本严格执行。
- **隐私**：打包和对外产物需去除绝对路径与内部信息（语义输入已做绝对路径清洗，见对应测试）。
- **release_packages/**：历史打包归档，**不是活代码**，改代码不要动它。
